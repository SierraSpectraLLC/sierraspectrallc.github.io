Connect

This page edits the text on your live site by committing directly to GitHub. It needs a token so GitHub knows it's you. Nothing is sent anywhere else.

Make the token narrow. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token. Repository access: only SierraSpectraLLC/sierraspectrallc.github.io. Permissions: Contents → Read and write, nothing else. Give it an expiry date. The token is stored in this browser only (localStorage), never committed. If you use a shared computer, hit "Forget token" when you're done.

How this works

Every box below is a piece of text on your site. Change it, hit Publish changes, and it's live. Changed boxes turn orange. Nothing is saved until you publish.

A few boxes contain link tags like <a href="#contact">text</a>. Edit the words between the tags and leave the pointy brackets alone.
